# Tang Nano 9k Structure

- **LUT4** (4-bit input Look Up Table) (16:1 Multiplexer, where 16-bit values are stored in SRAM)  
  - 8640

- **CFU** - Configurable Functional Unit (LUT4 + FF)  
  - 2160  
  - Configurable as Logic gates / Arithmetic Hardwares / SRAM-based on Logic / ALU / Memory Mode

- **Crystal Oscillator** - Acts as a clock  
  - 27 MHz

- **Flip-Flops**  
  - 6480

- **Shadow SRAM** - Derived from the CFU  
  - 17280 bits

- **Block SRAM** - On-Chip Hardware memory  
  - 26 × 18 Kbits

- **User Flash** - On-Chip Non-Volatile storage  
  - 608 Kbits

- **Multipliers**  
  - 20 × 18x18 Multipliers

- **PLLs** - Phase Locked Loops  
  - 2

- **Pseudo RAM** - In Package (Off-chip)  
  - 8 MBytes
